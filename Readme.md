# 养猫笔记 2.0


# 前言

不知不觉更新到2.0版本了，1.0版本前前后后markdown写了快2000行，没想到这么多，而且明确的感觉到还有疏漏的地方。

1.0版本整理大概的整理了不同角度的养猫笔记，汇总下来自己也大概对整个养猫这件事情有了一定的理解。

这下明确知道了这个大概的理解，那么接下来就是要开始正式的整理了。

首先是整理目录（2026/9/5开始计划，2026/X/X完成）
不知道会弄多久，不过整理目录应该问题不大。

（2026/9/5同下午）如果只是目录的话，其实已经完成了，确实不算很难。
但是考虑到完备性，与目录对应的开头废话介绍，确实还需要一些时间。

这个目标的2.0并不打算放很多详细的内容在里面。

- 在正文里我寻思着就把目录，以及一些相关的介绍指引放进来，主要用来方便后续补充修改以及查询。
- 然后具体的细节放在每个单独的文件里，这样只是看目录的人不会被具体的细节影响到观感，看细节的人也能明确自己需要看的内容有哪些。

其实一直觉得自己做的这些工作正常来说应该肯定已经有人做过整理，甚至已经整理成图书或者打印出来成文了。

但是为什么我要单独做这个东西？

因为人是会为了沉默成本付出更多的，我想我以后更加重视我的毛孩子。
我不知道以后的我会是怎样子，但是现在的我在试着绑架未来的我哈哈哈。

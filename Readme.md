# 2. 猫咪的选择
看到这里，既然决定了真的要养猫，那么就有这么几个问题。
- 通过什么渠道获取一只猫咪？
- 怎么选择合适的猫咪？
  - 自己所处的环境适合怎样的猫咪？
- 怎么保证猫咪的健康？
  - 不然开开心心买了只猫咪，结果是星期猫，这心态不崩了？

所以这一章节从两个方面对选择猫咪进行论述，分别是： **养猫渠道**，**选择猫咪**。

1. 其中**养猫渠道**介绍不同渠道方式获得猫咪的特点；
同时说明怎么在不同渠道下都能获取同样的健康的猫咪。

2. 而**选择猫咪**则从猫咪的种类开始介绍，为读者简单普及猫咪种类特点的知识；
随后简要介绍不同种类的猫咪的特点与适配环境，帮助不同人群选择自己合适的猫咪。
- 当然，这是是理性的选择挑选，仅用于部分“我想养猫而且我想省事”的人群
- 还有另外一种选择猫咪的方式，眼缘，一眼定终身。
  - 这种方式就不在这里额外说明了。

## 2.2 选择猫咪

### 一些废话
有的时候会觉得自己是读书读傻了哈哈，养猫选猫的第一反应是

2. 然后就是，“我怎么保证我的挑选范围就是完整的” 
3. 然后问题就变成了，“所有的猫咪一共有多少种？” 
4. 然后就想着在知道所有猫咪的种类情况下，一个个调研不同猫咪的养猫特点
5. 然后基于不同猫咪的特点，和自己的现实情况，去选择一个最合适自己的猫来保证这是最适合的。

如果说有读者能理解作者上述的想法，说明你也是被学习（科研）折磨（荼毒）的不轻哈哈哈。

# 3. 养猫前需要准备的东西
如果真的想要养猫，那么就要做好改造现有的家的准备。
比如添置适合猫猫的家具用品；为猫猫准备一些猫猫用的消耗品；
又或者改造一下家里的基础环境，毕竟猫猫作为新成员加入肯定会跟已有环境进行交互的。

如果不想看到自己喜欢的玻璃杯摔碎、垃圾桶被踢翻、桌面物品掉落一地、
沙发窗帘变流苏款式等等，那么一些对现有家里物品的基础改造和调整就是必须的。

那么这里就从三个方面说明养猫前所需要的准备：
1. 猫咪家具的准备（一些一次性/长期用品）
2. 猫咪消耗品的准备（猫砂/猫粮/猫零食等需要反复购买的东西）
3. 家里家具的调整（为现有物品提前做好防护、优化对猫有害的物品等）

## 3.1 基础物品（一次性购置）
养猫最终会准备的东西会很多，但是在最前期的时候其实要准备的不多。

准备那么多玩具啊，用品啊，其实说不定猫咪还不喜欢。
最开始只需要能保证最基础的养猫需求就好，多了其实也是增加自己的负担。
作者认为的话，更多的东西读者们知道知道其存在，具体的需求会在后面养猫过程种逐渐意识到其重要性，进而决定购买。

而不是在最开始的时候被要求买这个买那个，然后发现很多东西根本用不上。

所以在最开始的时候，只需要确认需要购置物品的最小集就好。

[3-1-养猫长期物品选择.md](3-1-%E5%85%BB%E7%8C%AB%E9%95%BF%E6%9C%9F%E7%89%A9%E5%93%81%E9%80%89%E6%8B%A9.md)

## 一些瞎扯

又不是写论文，那么严谨做什么。

这一节就主要是放一些猫咪的常识吧。虽然平常刷猫猫狗狗的视频，

而且很多所谓的常识，其实归根到底也都很简单——
把猫当人看，别把猫当傻子。

但小孩子也很清楚谁对他好谁对他不好。

## 言归正传

本节主要介绍些猫咪的常识，让读者了解猫咪的行为，习性，以及不同年龄的阶段的普遍状态。
但是在了解的基础上，也希望读者明白每个生命都是独立的个体。
统计有统计的意义，但是具体到每个个体请不要烙印标签。

大家长大也都是背着一个个标签过来的，也都层被各种各样的规训“常识”压的喘不过气。
- 你都多大人了，怎么还XXX
- 都什么时候了，你怎么还XXX
- 别人都XXX，你怎么还XXX
然后养猫也要把这些压力传递到毛孩子身上吗？
（说的有点沉重了，虽然猫猫不一定吃压力哈哈哈）

然后这节的内容大约是：
1. 猫咪不同年龄段的状态：同样一只猫猫，小时候调皮，少年稳重，青年粘人，老年安静。
不同时间段的状态肯定不一样，也让读者提前有所了解一般情况。
2. 猫咪的行为含义：猫猫的不同表现代表了猫猫的不同的想法和情绪，猫猫不会说话，
但是人要能看懂猫咪的行为动作。
3. 一些其他与猫咪相关的知识常识：一些上面不好分类的部分就都丢来这里作为知识储备了。
4. 猫咪的哲学思考：猫咪有没有哲学思考作者不知道，但是作者作为infj肯定是思考过很多东西。
当然，作者的思考都体现在这一整套养猫笔记的方方面面了。所以这里放的大多是其他养猫人的总结。

## 4.1 猫咪不同时间的成长状态
首先，即使是同一只猫咪，在不同的年龄段也会有不同的表现。

1. 刚到家的时候怂的到处都找不着猫
2. 刚刚认识人的时候怂怂的接触人
3. 熟悉后大胆的到处跑
4. 太熟了开始毫无边界感起来
5. 时间到了孩子长大了又不粘人了
6. 变成了高冷猫猫厌烦起人的接触了
7. 忽然年龄到了又不拒绝的似拒还迎的傲娇
8. 老年了闹不动了

同一只猫猫在不同阶段的表现不尽相同，但大体肯定是有一定的参考性的。
而这里更多的其实只是放一些猫咪一些可以被量化的共性数据，比如体重，进食量。
这些可以被良好量化的数据能更好的给以后养猫做参考。

## 4.2 猫咪的行为与含义

人和猫最大的不同在于：人用语言沟通，而猫用肢体沟通。

有的时候作者会觉得猫比人聪明。
为什么？因为有的猫听得懂人说的话，人却听不懂猫的“喵喵喵”。

所以在网上看到宠物说话按钮真的很心动，聪明的猫猫不仅听得懂人说的话，
甚至知道要怎么用人的词语来组成它想表达的意思。它和人之间就感觉只差一张说人话的嘴了。

跑题了。

所以人没有那么容易区理解猫的行为、肢体表达的意思。但神奇的是大部分猫的肢体语言是存在相似性的，
所以作为人，可以去了解那些行为的共性来提前对猫的行为和表达有一定的理解。

作者相信，只要能建立沟通，不同生物也都可以是朋友。

[4-2-猫咪行为.md](4-2-%E7%8C%AB%E5%92%AA%E8%A1%8C%E4%B8%BA.md)

# 8. 养猫的花销
有一个计算开支的习惯对于一个习惯计划人来说可太重要了。

对养猫经济的规划，虽然说不至于说细致准确到每天花多少钱的程度；也不至于说是能规划个三年五年的（其实还真说不准）。

但是对于正常情况下未来一两年的开支其实倒是可预见的。同时根据作者周围人调研的结果来看，其实养猫正常的开支都是不高的。

但是高的部分可能就比较夸张了，比如生病，生个大病，以及某些哈士奇的（“我有个上万的装修计划”）之类的装修计划。
可能才是养猫会出现的开支大头。

但是即使是这样的意外情况，其实也能被一定程度的提前了解……当然也只是提前了解，有些事情避免是无法避免的。
但是有提前了解，一方面看病的时候对于花费能有一定的预估，另一方面也是让自己做更多长期的预备。

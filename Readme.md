# 2. 猫咪的选择
看到这里，既然决定了真的要养猫，那么就有这么几个问题。
- 通过什么渠道获取一只猫咪？
- 怎么选择合适的猫咪？
  - 自己所处的环境适合怎样的猫咪？
- 怎么保证猫咪的健康？
  - 不然开开心心买了只猫咪，结果是星期猫，这心态不崩了？

所以这一章节从两个方面对选择猫咪进行论述，分别是： **养猫渠道**，**选择猫咪**。

1. 其中**养猫渠道**介绍不同渠道方式获得猫咪的特点；
同时说明怎么在不同渠道下都能获取同样的健康的猫咪。

2. 而**选择猫咪**则从猫咪的种类开始介绍，为读者简单普及猫咪种类特点的知识；
随后简要介绍不同种类的猫咪的特点与适配环境，帮助不同人群选择自己合适的猫咪。
- 当然，这是是理性的选择挑选，仅用于部分“我想养猫而且我想省事”的人群
- 还有另外一种选择猫咪的方式，眼缘，一眼定终身。
  - 这种方式就不在这里额外说明了。

## 2.2 选择猫咪

### 一些废话
有的时候会觉得自己是读书读傻了哈哈，养猫选猫的第一反应是
1. “我怎么保证我选择的猫就是最适合我的” 
2. 然后就是，“我怎么保证我的挑选范围就是完整的” 
3. 然后问题就变成了，“所有的猫咪一共有多少种？” 
4. 然后就想着在知道所有猫咪的种类情况下，一个个调研不同猫咪的养猫特点
5. 然后基于不同猫咪的特点，和自己的现实情况，去选择一个最合适自己的猫来保证这是最适合的。

如果说有读者能理解作者上述的想法，说明你也是被学习（科研）折磨（荼毒）的不轻哈哈哈。

但是除了那些理性的分析，权衡利弊以及选择……又或者说挑选……
- 实际上作者很不喜欢**挑选**这个词。
因为这个词明确的将人和毛孩子划分出了高位低位，但无法否认的是事实在一定程度上就是这样的。
即使再否认，在现代社会里想要让毛孩子获取人一样的权力是非常困难的事情。
- 不过毛孩子并不关心这么多，它只关心的只有一件事：“我们认可他”
  - 这便足够了。

而选猫这件事，作者其实早有了答案（狸花~）：
- 选一只本地品种的
- 选一只耐活的
- 然后还有另外一种可能，对上眼缘了

毕竟第一次养猫，作者第一次当爹，它第一次被养。大概率作者很多地方都做得不太好，
所以也希望毛孩子自己也能坚强点。
作者努力学，他努力活。

### 言归正传
除去了那些理性的，不带感情的分析，其实对不同的猫咪有所了解其实也有助于家长带娃。

不同的猫猫有着不同的特点，有的活泼好动，有的文静优雅。不同的猫猫有着不同的烦恼，
有些猫猫可能偶发某些情况，但是这个情况在其他猫猫那确实常见问题。

# 3. 养猫前需要准备的东西
如果真的想要养猫，那么就要做好改造现有的家的准备。
比如添置适合猫猫的家具用品；为猫猫准备一些猫猫用的消耗品；
又或者改造一下家里的基础环境，毕竟猫猫作为新成员加入肯定会跟已有环境进行交互的。

如果不想看到自己喜欢的玻璃杯摔碎、垃圾桶被踢翻、桌面物品掉落一地、
沙发窗帘变流苏款式等等，那么一些对现有家里物品的基础改造和调整就是必须的。

那么这里就从三个方面说明养猫前所需要的准备：
1. 猫咪家具的准备（一些一次性/长期用品）
2. 猫咪消耗品的准备（猫砂/猫粮/猫零食等需要反复购买的东西）
3. 家里家具的调整（为现有物品提前做好防护、优化对猫有害的物品等）

## 3.1 基础物品（一次性购置）
养猫最终会准备的东西会很多，但是在最前期的时候其实要准备的不多。

准备那么多玩具啊，用品啊，其实说不定猫咪还不喜欢。
最开始只需要能保证最基础的养猫需求就好，多了其实也是增加自己的负担。
作者认为的话，更多的东西读者们知道知道其存在，具体的需求会在后面养猫过程种逐渐意识到其重要性，进而决定购买。

而不是在最开始的时候被要求买这个买那个，然后发现很多东西根本用不上。

所以在最开始的时候，只需要确认需要购置物品的最小集就好。

## 3.2 基础耗材

养猫，尤其是不同阶段的猫咪所需要准备的物品（比如猫粮）其实还不太一样。

但是考虑到一般养猫大多数都是从幼猫开始养，当然从大猫开始也不是不行，
这些很多不是人能决定的。

然后养猫的耗材，主要其实应该就猫粮和猫砂，其准备和选择也没多复杂。
但考虑到耗材和长期使用的物品还是多少有区别的，所以便单开一节了。
